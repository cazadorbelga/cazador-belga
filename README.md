# Cazador Belga

Site web dédié aux chasseurs francophones souhaitant chasser en Espagne.

Le projet propose des guides pratiques, des retours d'expérience et des informations utiles pour comprendre les démarches et préparer sa chasse en Espagne.

## Stack technique

- Next.js
- React
- TypeScript
- Tailwind CSS
- Git / GitHub
- Déploiement prévu sur Vercel

## Développement local

Depuis le dossier du projet :

```bash
cd /c/dev/cb
npm run dev
```
